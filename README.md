## Overview
Lab 3 for CS1566 was to generate various triangles, draw them to the screen, and be able to toggle what is drawn.

## Tech Stack
- Programming: C, OpenGL
- Text Editor: VSCode

## Takeaways
Generating the first triangle and subsequently the square, which is just two more triangles, was very easy. I found that drawing out all the vertexes on a sticky note made everything a lot easier to write out. One struggle with this lab was generating the 3 rows of triangles. Conceptually it wasn't hard, but it was making sure they all fit within the screen properly (no stretching or overlap) was the annoying part. Another round of drawing on a sticky note help greatly with solving this problem. I wish I still had the sticky notes lying around to show them here.

Another struggle was toggling what is drawn to the screen and what isn't. I simply just kept reviewing the lecture recordings and reviewing the slides made available on the course page. In hindsight, it's not that complex at all. However, at the time, I remember this being a learning curve for me. Now looking at this code it really is just drawing a set range of vertices from an array.
